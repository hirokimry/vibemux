# ガードレールバイパスパターン

vibemux の `.claude/hooks/` に存在するガードレールで確認された、既知のバイパス経路と対策方針。

> **注意**: `.claude/hooks/` 配下は `install.sh --update` による自動生成物のため、
> 本リポジトリでの直接修正は次回更新で上書きされる。
> 問題は vibecorp upstream リポジトリで修正する。

---

## 1. `protect-branch.sh` — `git commit` 文字列検出のバイパス

**発見**: PR #27 レビュー指摘（CodeRabbit 確認済み）

### 問題

`protect-branch.sh` の `git commit` コマンド検出ロジックに、特定の入力形式でバイパスできる経路が存在する。

### 対策方針

- `.claude/rules/shell.md` の「コマンド判定」節に記載の正規化手順（環境変数プレフィックス除去、ラッパーコマンド除去、`basename` による絶対パス正規化）を適用すること
- 振る舞いの詳細は TODO コメントとして対象ファイルに既記録

### upstream 追跡

vibecorp リポジトリ Issue として追跡。本リポジトリでの修正は不要。

---

## 2. `team-auto-approve.sh` — プロセス置換検出漏れ

**発見**: PR #27 レビュー指摘（CodeRabbit 確認済み）

### 問題

コマンド検出ロジックが bash のプロセス置換構文 `<(...)` / `>(...)` を考慮していない。
これらの構文を使ったコマンドが検出をすり抜ける。

### 対策方針

コマンド文字列を判定する際はプロセス置換を展開・除去したうえで比較する。
`.claude/rules/shell.md` のコマンド正規化ルールと同様のアプローチを適用する。

### upstream 追跡

vibecorp リポジトリ Issue として追跡。本リポジトリでの修正は不要。

---

## 3. CISOエージェント — Write ツール権限の欠落

**発見**: PR #43 レビュー指摘（CodeRabbit 確認済み）

### 問題

`.claude/agents/ciso.md`（自動生成）に Write ツール権限が含まれておらず、
CISO エージェントが `.claude/knowledge/` 等へ判断記録を書き込めない状態になっている。

### 影響

- 判断ログの未記録（監査証跡の欠落）
- CISO ワークフローの step 4「判断の記録」が機能しない

### 対策方針

vibecorp プラグインのエージェント定義テンプレート（`ciso.md`）に
Write / Bash ツール権限を追加する。upstream 修正が優先。

---

## 参考: `.claude/` ファイルの取り扱い原則

`.claude/` 配下のファイルはすべて vibecorp プラグインによる管理成果物。
バイパス・権限不備を発見した場合は以下のフローで対処する:

1. コードレビューで指摘 → `対応不要`（上書きされるため）と返答
2. vibecorp upstream に Issue 起票
3. 本ファイルにバイパスパターンを記録（セキュリティ知見の蓄積）
